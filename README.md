# RD Photo & Signature Resizer

Android-first Flutter app for resizing passport photos and signatures.

## Features
- Select an image from gallery or take a photo
- Crop and rotate
- Resize by pixel dimensions
- Compress toward a target file size (20 KB to 2 MB)
- Preview, save to gallery, and share
- Bengali / English interface
- Google AdMob test banner
- Govt Job with RD YouTube link

## Build APK
GitHub Actions runs on pushes to `main` and can also be started manually from the Actions tab. Download the debug APK from the workflow run's Artifacts section.

The included AdMob IDs are Google's test IDs. Replace them with your own AdMob app and ad-unit IDs before publishing.

## Privacy
Images are processed locally on the device. The app does not upload selected photos or signatures to a server.

Always check the relevant recruitment notice for exact photo and signature specifications.
